Mode aperçu : les modifications sont gardées seulement dans ce navigateur. Une fois le site en ligne sur Cloudflare, elles seront enregistrées pour tout le monde.

Touchez une catégorie pour l'ouvrir. Décochez « Visible » pour retirer un produit de la carte sans le perdre, ou supprimez-le définitivement avec « Plus ». N'oubliez pas d'enregistrer en bas de l'écran.

Les options sont les choix proposés au client quand il touche un produit (viande, crudités, sauces…). Ici vous changez les choix, les suppléments et les images. Pour choisir quels produits proposent quelles options, ouvrez le produit dans « Produits » puis « Plus ».

Une promo s'affiche toute seule sur le menu client pendant les jours et les heures choisis (heure de Paris). Vous pouvez aussi baisser le prix de certains produits pendant la promo : l'ancien prix apparaît barré.

📺 Écran TV

Ouvrez /ecran en plein écran (touche F11) sur la TV du restaurant. Les promos en cours s'affichent en grand avec un visuel animé et le temps restant, puis la carte défile. Tout se met à jour seul quand vous enregistrez une promo.

Options : /ecran?promos=1 (seulement les promos) · /ecran?lang=en (en anglais) · /ecran?duree=15 (15 secondes par écran).

Nombre de tables

Deux créneaux possibles par jour (ex. midi et soir). Un créneau qui finit après minuit marche aussi (ex. 18:00 → 01:00). Le serveur peut toujours commander.

Code serveur (4 à 8 chiffres) pour la prise de commande sur /serveur

Le serveur choisit la table ou « à emporter », même si les commandes clients sont désactivées. Votre mot de passe admin marche aussi.

Les commandes arrivent sur la page Cuisine (à ouvrir sur l'ordinateur relié à l'imprimante). Décochez pour couper les commandes, par exemple quand c'est fermé : le client verra « montrez cet écran au comptoir ».

Ce QR code ouvre le menu. Imprimez-le et posez-le sur les tables. Il ne change pas quand vous modifiez les prix ou les produits.

QR codes des tables

Un QR code par table : le client qui le scanne peut envoyer sa commande en cuisine avec le bon numéro de table. Imprimez la planche, découpez et collez sur chaque table.

Chaque QR contient un code secret propre à la table : taper l'adresse à la main ne suffit pas pour commander. Les QR se gardent tant que vous ne changez pas le code.
